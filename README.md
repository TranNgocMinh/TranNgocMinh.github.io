# Minh Tran — Web Developer Portfolio

Personal portfolio for freelance web development. Built with HTML, CSS, JavaScript and no external dependencies.

## Website

After deployment: **https://tranngocminh.github.io/**

## Features

- Responsive, accessible layout and mobile navigation
- Filterable project showcase
- Interactive Taskboard: create, edit, delete, search, status columns, browser localStorage
- Interactive Quote Builder: select project types and features, calculate illustrative hour/budget estimates, copy summary
- Descriptive metadata, sitemap and favicon

## Local development

Open `index.html` directly, or run:

```bash
python -m http.server 8080
```

Open http://localhost:8080 in your browser.

## GitHub Pages deployment

Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

The repository also contains legacy ConvNeXt Python research scripts (`myconvnext.py` and `myconvnext_train.py`). These are kept unchanged and are not used by the portfolio.

## Portfolio integrity

Taskboard and Quote Builder are independent portfolio exercises, **not paid client work**. AI Tutor links to a research prototype with publicly available source. More projects will be added after verification and testing. No testimonials, client counts or commercial experience are fabricated.

## Privacy

The Taskboard stores tasks only in your browser's localStorage. Neither demo transmits user inputs to any server. Avoid entering personal or sensitive information.
